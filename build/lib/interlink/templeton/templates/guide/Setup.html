2.1 Setup ¶

Setting up interlink is very easy. I like to use some boilerplate for every flask project, as I’m sure most people do. This isn’t a tutorial on Flask, so we’ll skip setting up the project. The point is to get it from github to your site-packages directory.

  1. Make your flask project and create the virtual env
  2. Download:
    • cd ~/path/to/project/project/lib/python3.*/site-packages
    • git clone https://github.com/padsRepo/interlink.git
  3. Install requirements:
    • path/to/project/project/bin/python path/to/project/project/bin/pip install flask, mysql-connector
  4. Add to your project:
    • from interlink import *

Since I’m cheap, I just copy and past it into the site-packages directory of the project I’m working on. Of course, you’ll need Flask, and mysql.connector set up as a dependancy for this to work. I think that should go without saying if you’re using forms and reports in flask. The first thing you want to do is start your flask project, and make your webpages.

FIRST WAY: In your __init__.py file you need to create these ENV Vars for the API to find, and import the Blueprint: (I usually add these to the "activate" file for starting the virtual env.) 

import os
from flask import Flask, Blueprint, flash, render_template, request, session, redirect, url_for, send_from_directory

from views import viewsBP

KEY = os.urandom(16)
os.environ['SECRET_KEY'] = str(KEY)
os.environ['DB_USER'] = 'username'
os.environ['DB_PASS'] = 'db password'
os.environ['BASE_DIR'] = os.path.dirname(__file__)
os.environ['LOG_DIR'] = os.environ.get('BASE_DIR') + '/log'
os.environ['whitelist'] = '["127.0.0.1", "192.168.0.*", "10.0.0.*"]'
os.environ['blacklist'] = '["My_brothers_smartphone_ip"]'

app = Flask(__name__)
app.config.from_mapping(SECRET_KEY=os.environ.get("SECRET_KEY"))
app.config['UPLOAD_FOLDER'] = 'repo/'

from interlink import *
app.register_blueprint(viewsBP)
app.register_blueprint(templetonBP)
app.register_error_handler(404, url_not_found)
app.register_error_handler(500, internal_error)

if __name__ == '__main__':
  app.run()
else:
  app.run(debug=True, host='0.0.0.0', port='8000')

You’ll see that we imported templetonBP from interlink, then just registered the Blueprint with app_register_blueprint(templetonBP). We also imported url_not_found, and internal_error because PADS has a built in generic url handler. We register those with app.register_error_handler(404, url_not_found), and app.register_error_handler(500, internal_error) respectively. The rest of it comes from your own custom urls that you generate from the app.register_blueprint(viewsBP) line. The DB name needs to be named exactly as it’s named in SQL. DB_USER and DB_PASS must be named exactly that for the formulator to find it. The SECRET_KEY is needed for flask.session. Notice that we import interlink further down the file, so the env vars load first and prevents recursion.
