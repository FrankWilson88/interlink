1.1 Options ¶

pads -S -[b,u,i,l,d,r:,m,s,h,v] [name...]

System Module - For automation of running system commands on your machine.

‘-b’

Backup System

‘-u [name...]’

Update machine. Supply name of package to install.

‘-i’

Update pads’ info page

‘-l’

List packages on this machine

‘-d’

Update pads’ man page

‘-r <name...>’

Remove supplied packages

‘-m’

Set up mariadb

‘-s’

Show system information

‘-h’

Show help

‘-v’

Show help

‘pads -P -[p:,f:,g:,h,v] -[m,s,d] <name>’

Project Module - For managing projects that are not bash

‘-p -[m,s,d] <name>’

Manage a python project. Saved to: [dir]

‘-f -[m,s,d] <name>’

Manage a flask project. Saved to: [dir]

‘-g -[m,s,d] <name>’

Manage a pygame project. Saved to: [dir]

‘-h’

Show help

‘-v’

Show help

‘pads -R -[s:,v,h] <name...>’

Run Module - Running misc scripts. Good for testing

‘-s’
passgen

Generate a random password

note

Take a note

buildpkg

Build Package to install

conkystart

Start Conky panels

timer <int>

Start a countdown timer for n seconds

progress

Show a progress bar

resetpath

Reset default $PATH

‘-h’

Show help

‘-v’

Show version
